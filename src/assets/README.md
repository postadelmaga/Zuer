# Font embeddati

`Hack-*.ttf` — famiglia **Hack** (Regular/Bold/Italic/BoldItalic), lo stesso
monospace di default di egui, embeddato nel binario per la resa nativa del testo
(vedi `src/glyph.zig`).

Hack è distribuito sotto la [Hack Open Font License](https://github.com/source-foundry/Hack/blob/master/LICENSE.md)
(MIT + Bitstream Vera), che ne consente l'inclusione e la ridistribuzione.
Upstream: https://github.com/source-foundry/Hack

`LiberationSans-*.ttf` — famiglia **Liberation Sans** 2.1.5 (Regular, Bold,
Italic, BoldItalic), il testo proporzionale del markdown a schermo e in stampa
(vedi `src/glyph.zig`, famiglia `prose`). Distribuita sotto la
[SIL Open Font License 1.1](https://github.com/liberationfonts/liberation-fonts/blob/main/LICENSE),
che ne consente l'inclusione e la ridistribuzione insieme al software.
Upstream: https://github.com/liberationfonts/liberation-fonts
